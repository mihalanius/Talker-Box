Talker Box - Рекомендации по улучшению проекта
=============================================

Дата анализа: 11.09.2026
Версия проекта: v2.0

===== 1. АРХИТЕКТУРА И СТРУКТУРА

1.1. Дублирование кода горячих клавиш
Проблема: Есть два файла с похожей функциональностью - hotkey_hook.py и hotkey_listener.py. 
Оба реализуют WH_KEYBOARD_LL хук.
Рекомендация: Объединить в один модуль или чётко разделить ответственность:
- hotkey_hook.py - для in-process хука (используется в main.py)
- Удалить hotkey_listener.py если он не используется, или перенести в отдельную утилиту

1.2. Централизация путей
Проблема: Функция _get_base_dir() дублируется в 3 файлах (main.py, transcriber.py, settings_manager.py).
Рекомендация: Использовать существующий paths.py для всех путей:

from paths import get_base_dir, get_models_dir, get_sounds_dir

===== 2. КАЧЕСТВО КОДА

2.1. Обработка ошибок
Проблема: Много try-except с пустым pass (например, в settings_manager.py:39, sounds.py:17, recorder.py:52).
Рекомендация: Добавить логирование ошибок:

except Exception as e:
    log("ERROR", f"Failed to load settings: {e}")

2.2. Волшебные числа
Проблема: В коде много хардкодов (размеры, тайминги, цвета):
- main.py:485 - setFixedSize(585, 419)
- waveform.py:18 - setFixedSize(200, 30)
- main.py:149 - timer.start(150)
Рекомендация: Вынести в константы:

# config.py
WINDOW_WIDTH = 585
WINDOW_HEIGHT = 419
WAVEFORM_WIDTH = 200
WAVEFORM_HEIGHT = 30
STARS_ANIMATION_INTERVAL = 150

2.3. Импорты внутри функций
Проблема: В main.py:153, waveform.py:168 импорты внутри функций (import random, import math).
Рекомендация: Перенести импорты в начало файла для улучшения производительности.

===== 3. UI/UX

3.1. Разделение UI логики
Проблема: main.py содержит 569+ строк с UI компонентами и бизнес-логикой.
Рекомендация: Разделить на модули:
- ui/main_window.py - главное окно
- ui/components.py - NeonLabel, NeonCheckBox, StarsWidget и др.
- ui/styles.py - константы стилей

3.2. Хардкоды стилей
Проблема: Цвета и стили разбросаны по коду:
- main.py:486-506 - stylesheet для QMainWindow
- main.py:71-79 - NeonFrame цвета
Рекомендация: Создать ui/theme.py:

class Theme:
    BG_TOP = "#0d1225"
    BG_MIDDLE = "#111830"
    BG_BOTTOM = "#0a0f1f"
    ACCENT_GREEN = "#00ff88"
    ACCENT_BLUE = "#00f7ff"
    TEXT_COLOR = "#e0e0e0"

===== 4. ПРОИЗВОДИТЕЛЬНОСТЬ

4.1. Оптимизация анимации
Проблема: StarsWidget обновляется каждые 150мс с перерисовкой 50 звёзд.
Рекомендация: 
- Использовать GPU-ускорение через QOpenGLWidget
- Или уменьшить количество звёзд/интервал обновления

4.2. Загрузка модели
Проблема: Модель GigaAM (220МБ) загружается синхронно при старте, может блокировать UI.
Рекомендация: Загружать модель в отдельном потоке с индикатором прогресса.

===== 5. БЕЗОПАСНОСТЬ

5.1. Отсутствие валидации
Проблема: Нет валидации входных данных в settings_manager.py.
Рекомендация: Добавить валидацию:

def set(self, key, value):
    if key == "hotkey" and not self._validate_hotkey(value):
        return
    self.settings[key] = value
    self.save()

===== 6. ЗАВИСИМОСТИ И СБОРКА

6.1. Жёсткие пути в build.bat
Проблема: build.bat:2 - cd /d "D:\OpenCode_Arhive\Talker Box" - жёсткий путь.
Рекомендация: Использовать относительные пути:

cd /d "%~dp0"

6.2. Отсутствие requirements.txt
Проблема: Нет файла с зависимостями для разработки.
Рекомендация: Создать requirements.txt:

PyQt6==6.6.1

===== 9. КОНФИГУРАЦИЯ

9.1. Устаревшие настройки
Проблема: settings.json содержит active_model и models (v2.0 их удалила).
Рекомендация: Очистить settings.json от устаревших полей.

9.2. Отсутствие миграции настроек
Проблема: Нет механизма миграции при обновлении версии.
Рекомендация: Добавить version в settings и миграцию:

SETTINGS_VERSION = 2
def migrate_settings(self):
    if self.settings.get("version", 1) < 2:
        # миграция с v1 на v2
        self.settings.pop("models", None)
        self.settings["version"] = 2
