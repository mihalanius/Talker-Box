Talker Box — Руководство пользователя

Быстрый старт

  1. Запустите программу
  2. Откройте любое текстовое поле (блокнот, браузер, мессенджер)
  3. Активируйте поле ввода нажатием ЛКМ
  4. Нажмите и удерживайте горячую клавишу (Ctrl+Win по умолчанию)
  5. Говорите
  6. Отпустите клавишу — текст вставится автоматически

Режимы работы

  • Hold (удерживай) — запись идёт пока зажата клавиша. Отпустил — распознало и вставило
  • Toggle (нажал-нажал) — первое нажатие начинает запись, второе останавливает

Настройки

  • Режим — выбор между Hold и Toggle
  • Авто-отправка — если включено, текст вставляется и отправляется нажатием Enter
  • Горячая клавиша — нажмите кнопку и затем нажмите нужную комбинацию клавиш
  • Сменить Модель — загрузка другой языковой модели из папки

Горячие клавиши

  • Можно задать любую комбинацию: Ctrl+Win, Ctrl+Shift, F9 и т.д.
  • Для смены — нажмите кнопку с текущей комбинацией, затем нажмите новую

Модели

  • Программа поддерживает модели sherpa-onnx, vosk, whisper
  • Чтобы загрузить модель — нажмите «Сменить Модель» и выберите папку с моделью
  • Программа автоматически определит тип модели

Система

  • Программа сворачивается в трей при закрытии окна
  • Для полного выхода — ПКМ по иконке в трее → Выход
