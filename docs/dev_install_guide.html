Короткий чек-лист

Готовый установщик TalkerBoxSetup.exe этого НЕ требует — там всё внутри. Здесь только запуск из папки проекта через start.bat.

  • Python 3.13 (64-bit) — установить
  • Visual C++ Redistributable 2015–2022 (x64) — обычно уже есть, проверить
  • Папка проекта с исходниками (src\, requirements.txt, батники)
  • Модель models\GigaAM — 4 файла, 221 МБ
  • setup.bat — создаёт venv и ставит пакеты (один раз)
  • start.bat — запуск

1. Python 3.13 обязательно

Скачать: python.org/downloads/windows — Windows installer (64-bit), версия 3.13 (на эталонной машине — 3.13.15).

При установке:

  • галочка Add python.exe to PATH — можно поставить (удобнее), но setup.bat её не требует: он сам ищет Python в %LOCALAPPDATA%\Programs\Python\Python313 и C:\Program Files\Python313;
  • Install launcher for all users — оставить по умолчанию.

Проверка в «Командной строке»:

cmdpy -3.13 -V

Ожидаемо: Python 3.13.x. Если py не найден — проверить полный путь:

cmd"%LOCALAPPDATA%\Programs\Python\Python313\python.exe" -V
Python 3.12 рядом не мешает — setup.bat ищет именно 3.13. Проект проверен на 3.13.15.

2. Visual C++ Redistributable проверить

Нужен для PyQt6 и sherpa-onnx. Лучше поставить заранее:

ссылкаhttps://aka.ms/vs/17/release/vc_redist.x64.exe

Если он уже стоит, установщик предложит «Repair / Uninstall» — можно просто закрыть.

3. Папка проекта

Вариант А — с историей git

cmdgit clone https://github.com/mihalanius/Talker-Box.git "D:\OpenCode_Arhive\Talker Box"

Вариант Б — скопировать папку целиком

Нужны src\, requirements.txt, батники, fonts\, sounds\, vocabularies\.

Путь с пробелами (D:\OpenCode_Arhive\Talker Box) работает — все батники используют %~dp0 и cd /d, запускать можно откуда угодно.
Копировать venv\, dist\, build\, __pycache__\ не нужно — создаются заново. Но и мешать не будут.

5. Установка пакетов: setup.bat обязательно

Двойной клик по setup.bat в папке проекта. Что он делает:

  1. ищет Python 3.13 (перебор известных путей → where python);
  2. если venv\ нет — создаёт виртуальное окружение на этом Python;
  3. обновляет pip и ставит пакеты из requirements.txt;
  4. пишет Setup complete. Run start.bat to launch. и ждёт нажатия клавиши.
Пакеты ставятся внутрь venv — система не засоряется. venv привязан к конкретному Python: если Python переустановить, окружение перестанет работать (лечится удалением venv и повторным setup.bat).

Что должно стоять после setup.bat

cmdvenv\Scripts\python.exe -m pip list

Ожидаемые пакеты (версии эталонные, допускаются более новые):

ПакетВерсияЗачем нужен
PyQt6 (+ PyQt6-Qt6, PyQt6-sip)6.11.0 / 6.11.2 / 13.13.0интерфейс программы
sounddevice0.5.6запись с микрофона (PortAudio внутри пакета)
numpy2.5.4обработка аудио
sherpa-onnx (+ sherpa-onnx-core)2.0.0распознавание речи GigaAM
comtypes1.4.17UI Automation — позиция каретки для облачка
pywin32-ctypes0.2.3Win32 API: хук клавиатуры, SendInput
pyperclip1.11.0остался с ранних версий, в работе не используется
pyinstaller ставится не в setup.bat, а в build.bat — он нужен только для сборки exe.

Установка вручную (если не хочется батника)

Из папки проекта — ровно то же, что делает setup.bat:

cmd"%LOCALAPPDATA%\Programs\Python\Python313\python.exe" -m venv venv
venv\Scripts\python.exe -m pip install --upgrade pip
venv\Scripts\python.exe -m pip install -r requirements.txt

6. Запуск

cmdstart.bat

start.bat проверяет наличие venv (если нет — сам вызовет setup.bat) и запускает venv\Scripts\python.exe src\main.py. Окно консоли остаётся открытым — туда пишутся логи.

Без чёрного окна консоли

cmdvenv\Scripts\pythonw.exe src\main.py

Как понять, что всё поднялось

talkerbox.logMIC_SELECTED | (системный по умолчанию) -> device=None
MODEL_LOADED | GigaAM v3 trans-punct

Модель грузится ~2–5 секунд. Дальше программа висит в трее, горячая клавиша по умолчанию Ctrl+Win.

7. Если не запускается

ERROR: Python 3.13 not found

Python не установлен в стандартный путь. Проверить: where python. Если находит 3.12 или ничего — переустановить 3.13 из python.org (или вписать свой путь в setup.bat).

'python' is not recognized

Python не в PATH. Это не мешает start.bat, но для команд вручную используйте полный путь "%LOCALAPPDATA%\Programs\Python\Python313\python.exe".

Ошибка при pip install (таймаут, обрыв)

Плохой канал. Повторить setup.bat; при повторяющихся обрывах — с таймаутом и ретраями:
cmdvenv\Scripts\python.exe -m pip install -r requirements.txt --timeout 60 --retries 10

ImportError: DLL load failed

Не установлен Visual C++ Redistributable x64 (пункт 2) или стоит 32-битный Python. Нужен 64-bit.

Программа открылась, но текст не распознаётся

Нет модели: проверить models\GigaAM (все 4 файла), в talkerbox.log искать MODEL_ERROR / MODEL_LOADED. При наличии файлов, но ошибке — модель повреждена при скачивании (размер encoder.int8.onnx должен быть ≈ 224 МБ).

Микрофон молчит

Настройки → строка «Микрофон» → выбрать устройство; в Windows «Параметры → Конфиденциальность → Микрофон» разрешить доступ приложениям.

Горячая клавиша не срабатывает

В трее висит старая копия Talker Box (хук занимает комбинацию). Диспетчер задач → завершить все TalkerBox.exe / python.exe / pythonw.exe этого проекта, запустить заново. Если не помогает — не запускать от имени администратора (хук клавиатуры в другом уровне целостности не видит нажатий).

venv сломался после переустановки Python

Fatal error in launcher, пустой pip list → удалить папку venv и запустить setup.bat заново.

Кракозябры в консоли

MIC_SELECTED | (����...) — это кодировка консоли, на работу не влияет. Записи в talkerbox.log пишутся в UTF-8 корректно.

Всё это рабочие данные — можно удалять по одному, программа создаст заново.

9. Обновление проекта

cmdgit pull

Если менялся requirements.txt — повторить setup.bat. Дальше обычный start.bat.

Сборка установщика: build.bat (PyInstaller) → затем ISCC.exe installer\talkerbox.iss.

10. Требования к машине

  • Windows 10/11, 64-bit
  • ~700 МБ свободного места (venv ~340 МБ + модель 221 МБ)
  • 4 ГБ ОЗУ минимум (проверено на 14 ГБ; модель int8 работает на CPU, видеокарта не нужна)
  • Любой микрофон — встроенный, гарнитура, USB-петличка
