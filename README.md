# Talker Box

Голосовой ввод текста для Windows. Подходит для набора текста в word, общения в телеграмм и других мессенджерах. Идеально подходит для работы с ИИ-агентами и вайбкодинга — общайтесь голосом, ставьте задачи кодинг-ассистентам без печатания на клавиатуре.

## Зачем это нужно

При работе с AI-агентами (Claude Code, ChatGPT, OpenCode, Cursor, Copilot и др.) приходится много печатать. Talker Box позволяет:
- Говорить и распознавать текст — текст мгновенно вставляется в чат с агентом (поле ввода).
- Отправлять сообщения голосом — функция «авто-отправка» (Enter) отправляет сообщение сразу по окончании распознавания голоса (позволяет экономить время при длительном общении).
- Не отрываться от кода — рука остается на мышке и не прыгает постоянно для нажатия кнопки.
- При работе с мессенджерами и текстовыми программами, также создает удобство в общении и экономит время на набор текста руками по клавиатуре.

## Возможности

- Автоматическая вставка текста в активное поле (чат AI-агента)
- Автоотправка (Enter) — говорите и сообщение улетает агенту
- Два режима записи:
  - **Toggle** — нажал hotkey → запись, нажал → стоп + вставка
  - **Hold** — зажал hotkey → запись, отпустил → вставка
- Менеджер голосовых моделей (Sherpa-Onnx, Whisper, Vosk)
- Автозапуск при загрузке Windows
- Работа в системном трее — не мешает работе

## Установка

1. Скачайте релиз с GitHub Releases
2. Запустите `TalkerBoxSetup.exe`
3. Следуйте инструкциям установщика

## Горячие клавиши

| Режим | Клавиша | Действие |
|-------|---------|----------|
| Hold | Ctrl | (Зажал и удерживаешь) = запись  → **Сказал текст** → (отпустил) = вставка и отправка текста |
| Toggle | Ctrl | (Нажал/отпустил) = запись  → **Сказал текст** → (нажал/отпустил) = стоп и отправка текста |
|  Действие клавиши (хоткей) может назначаться другой клавише или двум любым клавишам, типо (Ctrl+Win) | 

## Совместимость с программами и AI-агентами

Работает с любым текстовым полем:
- **Telegramm** — голосовое управление в месенджере
- **OpenCode** — голосовое управление в терминале
- **Cursor** — общение с AI в IDE
- **GitHub Copilot Chat** — голосовые задачи
- **Aider** — вайбкодинг голосом
- **Claude / ChatGPT** — веб-интерфейсы
- **Любой другой AI-ассистент**
- **Word** — голосовой набор текста в документах Офис.

## Модели

Поддерживаемые типы:
- **Sherpa-Onnx** — легковесные модели (100 - 215 МБ), работают оффлайн
- **Whisper** — тяжелые модели (1-3 ГБ), высокая точность
- **Vosk** — альтернативные модели
- **По умолчанию** — установлена легковесная модель GigaAM v3 (215 МБ), работает оффлайн
