# Talker Box

Голосовой ввод текста для Windows. Идеально подходит для работы с ИИ-агентами и вайбкодинга — общайтесь голосом, ставьте задачи кодинг-ассистентам без клавиатуры.

## Зачем это нужно

При работе с AI-агентами (Cursor, Copilot, OpenCode, Aider и др.) приходится много печатать. Talker Box позволяет:

- Говорить — текст мгновенно вставляется в чат с агентом
- Отправлять голосом — авто-Enter отправляет сообщение
- Не отрываться от кода — руки остаются на мышке

## Возможности

- Автоматическая вставка текста в активное поле (чат AI-агента)
- Автоотправка (Enter) — говорите и сообщение улетает агенту
- Два режима записи:
  - **Toggle** — нажал hotkey → запись, нажал → стоп + вставка
  - **Hold** — зажал hotkey → запись, отпустил → вставка
- Встроенная модель GigaAM v3 (русский, с пунктуацией) — работает офлайн, выбор моделей не нужен
- Автозапуск при загрузке Windows
- Работа в системном трее — не мешает работе

## Установка

1. Скачайте релиз с GitHub Releases
2. Запустите `TalkerBoxSetup.exe`
3. Следуйте инструкциям установщика

## Горячие клавиши

| Режим | Клавиша | Действие |
|-------|---------|----------|
| Toggle | Ctrl+Win | Нажал → запись, нажал → стоп |
| Hold | Ctrl+Win | Зажал → запись, отпустил → вставка |

## Совместимость с AI-агентами

Работает с любым текстовым полем:
- **OpenCode** — голосовое управление в терминале
- **Cursor** — общение с AI в IDE
- **GitHub Copilot Chat** — голосовые задачи
- **Aider** — вайбкодинг голосом
- **Claude / ChatGPT** — веб-интерфейсы
- **Любой другой AI-ассистент**

## Модели

В программу зашита одна модель — **GigaAM v3 trans-punct** (sherpa-onnx, NeMo transducer, ~220 МБ):
русский язык, транскрипция + пунктуация, работа полностью офлайн, CPU (int8). Выбора моделей в
интерфейсе нет.

Ссылка: [sherpa-onnx-nemo-transducer-punct-giga-am-v3-russian-2025-12-16](https://huggingface.co/csukuangfj/sherpa-onnx-nemo-transducer-punct-giga-am-v3-russian-2025-12-16)

## Разработка

Нужен Python 3.13 (64-bit). Дальше — один двойной клик:

```bat
install_dev.bat   :: проверяет окружение, ставит пакеты, качает модель GigaAM, проверяет запуск
start.bat         :: запуск из исходников (venv\Scripts\python.exe src\main.py)
```

`install_dev.bat --check` — только проверить, ничего не меняя; `--run` — установить и сразу
запустить. Под капотом — `setup_dev.py` (лог пишется в `setup_dev.log`).

Модель распознавания (GigaAM v3, 220 МБ) лежит в `models\GigaAM\` — скрипт скачает её сам,
если папки нет.

Подробно, по шагам и с разбором ошибок: [docs/dev_install_guide.md](docs/dev_install_guide.md)
(в браузере — [docs/dev_install_guide.html](docs/dev_install_guide.html)).
