# Talker Box

Голосовой ввод текста для Windows с поддержкой множества моделей распознавания.

## Возможности

- Автоматическая вставка текста в активное поле
- Автоотправка (Enter) с возможностью включения/выключения
- Два режима записи:
  - **Toggle** — нажал hotkey → запись, нажал → стоп + вставка
  - **Hold** — зажал hotkey → запись, отпустил → вставка
- Менеджер голосовых моделей
- Автозапуск при загрузке Windows
- Работа в системном трее

## Установка

1. Скачайте релиз с GitHub Releases
2. Запустите `TalkerBoxSetup.exe`
3. Следуйте инструкциям установщика

## Горячие клавиши

| Режим | Клавиша | Действие |
|-------|---------|----------|
| Toggle | Ctrl+Win | Нажал → запись, нажал → стоп |
| Hold | Ctrl+Win | Зажал → запись, отпустил → вставка |

## Модели

Поддерживаемые типы:
- **Sherpa-Onnx** — легковесные модели (215 МБ)
- **Whisper** — тяжелые модели (1-3 ГБ)
- **Vosk** — альтернативные модели

## Разработка

```bash
pip install -r requirements.txt
cd src
python main.py
```
